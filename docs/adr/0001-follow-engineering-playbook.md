# ADR-0001: Follow the engineering playbook

- Date: 2026-10-23
- Status: Accepted

## Context

This project started from the engineering playbook's starter at playbook commit `9302f13365e2034bdf01d3c388a7d2816b5ed945`. The playbook asks eight questions and gives a default answer to each.

It replaces an existing product, migrated one capability at a time from `/Users/tomchen/Codespace/shared-expense-tracker-baseline` at commit `1aceb68e8759b528ac430a36f7e498cf70090e76`.

## Decision

- Strictness (chapter 0): level 1, a product maintained long-term. Level-2 areas: split and settlement amounts, and offline sync.
- Changes that merge without a human looking: none
- Deviations from the playbook defaults: none

## Consequences

Later deviations get their own ADR.
