## 摘要

把 baseline（`/Users/tomchen/Codespace/shared-expense-tracker-baseline` 的 `1aceb68`）手機 app 已經做得到的功能搬進這個 repo：記帳和分攤、分組、分類管理、支出分析。一次搬一個 capability：規格作者對照 baseline 的程式和測試，寫 spec 和驗收測試；實作者只搬 spec 要求的部分（`AGENTS.md` 的 Migration）。

## 動機

讓情侶和小團體一起記帳、分攤支出。baseline 已經能在一支手機上記帳、分攤、分組、管理分類、看支出分析，但它沒有 spec，程式也依類型分散在各個資料夾，capability 對不到程式的邊界。先重建，之後每個新功能都能建立在 spec、測試和清楚的邊界上。

## 驗證問題

v2 的手機 app 能不能取代 baseline？也就是 baseline 手機 app 做得到的事，v2 都做得到，而且每一條規則都有 spec 和通過的驗收測試。

## 原則

- 沒有網路也能記帳：重建後的手機 app 記帳不能需要網路。

## 不做

- 加 baseline 沒有的功能：這個階段的驗證問題是「能不能取代 baseline」，混進新功能就回答不了。
- 搬 baseline API 裡手機還沒用到的部分（註冊、登入、同步）：留到需要它們的階段再搬。

## 未決問題

- 各 capability 的搬移順序：開始重建時，依 capability 之間的相依關係決定。
