## 摘要

邀請伴侶或朋友加入同一個群組，也就是共同帳本，各自在手機上記帳；連上線之後，每個人手機上的資料一致，不遺失、不重複。不用註冊：手機第一次建立或加入共同帳本時，才產生給伺服器認得的身分。伺服器只轉送加密過的變更，看不到帳的內容（ADR-0003、ADR-0007）。先定好手機和 API 之間的資料約定，再接上同步。這個階段做完，就是第一個對外版本，是手機 app。

## 動機

記帳是基礎；共同帳本讓個人和共同的支出記在同一個地方，不必分散記錄、事後反覆對帳。沒有它，就只是一個人用的記帳 app。

## 驗證問題

兩個人在各自的手機上離線記帳，連上線之後資料是否一致，沒有遺失也沒有重複，而且被移除的手機立刻失去存取權？

## 原則

身分：

- 第一次需要伺服器時，才產生身分：建立或加入共同帳本之前，App 不連伺服器。
- 伺服器只知道最少的東西：每支手機在伺服器上只有一個隨機 ID、一把公開金鑰、它屬於哪些群組，以及推播用的代碼，沒有名字、Email 或電話。
- 用金鑰證明身分：手機的私鑰只存在 `expo-secure-store`，從不離開手機；每個請求都用私鑰簽名。
- 這個階段，一位成員由一支手機代表。換手機用換機碼；手機遺失時，用「接手」。

邀請和加入：

- 一個群組的邀請是一條連結，QR code 是同一個邀請；可以給好幾個人用，7 天後失效，建立的人可以隨時撤回。連結裡只有邀請代號，沒有帳本內容，也沒有鑰匙。
- 加入要經過一位現有成員同意，同意的人會看到「Bob 想以『Bob』加入」。
- 加入時選自己是哪位成員：建立一位新成員，或選群組裡已經有、但還沒有手機代表的成員，例如先被記進帳、後來才裝 App 的朋友。
- 成員都一樣大：每位成員都能邀請、同意加入、移除別人；有人加入或被移除，所有成員都看得到。
- 還沒裝 App 的人點到連結，先到網頁下載，裝好之後再點一次。

換手機、遺失和移除：

- 換機碼：從舊手機產生，24 小時有效，只能用一次。舊手機把全部資料打包，用從換機碼算出的金鑰加密後暫放在伺服器；新手機輸入換機碼下載並匯入，打包格式沿用手動匯出入的檔案。身分轉到新手機後，舊手機的授權立刻失效，暫放的資料也刪除。
- 接手：手機遺失時，新手機重新被邀請，加入時選「接手」原本的成員；同意之後，舊手機立刻失去存取權，過去的紀錄照樣接得上。
- 移除或退出：手機的存取權立刻失效；那位成員和他記過的支出、分攤都留在群組裡。被移除或退出的手機上，留一份停在當時的唯讀副本。
- 最後一位成員退出時，伺服器上的這個群組就刪除。

加密：

- 共同帳本的事件在手機上加密後才上傳，每個群組一把鑰匙。
- 同意加入時，同意的那支手機把鑰匙加密後交給新手機；有成員被移除時，留下來的其中一支手機產生新鑰匙，再交給其他成員。
- 伺服器只看得到外圍資訊：哪些手機屬於哪個群組、什麼時候同步、資料有多大，看不到內容。
- 加密用知名的函式庫和標準做法，不自己發明。

合併和衝突：

- 一個欄位一個欄位合併。同一個欄位，修改時間較晚的贏；時間會參考手機看過的最新時間，兩邊一樣時依裝置 ID 決定，所以每支手機算出的結果都一樣。
- 金額、幣別、付款人和分攤是一組，要換就整組一起換。
- 刪除比修改優先。
- 每次修改都記下它是根據哪一個版本改的。金額那一組被同時修改、你的修改被蓋掉時，那筆支出會掛上標記，例如「Bob 改成 350，你剛才改成 320」，可以選保留或改回。其他欄位安靜合併。
- 合併後會違反規則的變更，每支手機都不套用，並告訴記的人。
- 收到別人新增的支出，如果跟你記過的金額、幣別、日期都一樣，就掛上「可能重複」；可以刪掉其中一筆，或按「不是重複」，這個決定會同步給其他成員。
- 標記是圖示加文字，不只靠顏色；群組最上面顯示有幾筆需要確認；處理完標記才消失。金額的提醒不能關掉。

同步狀態和通知：

- 平常不顯示同步狀態。還沒上傳的支出顯示時鐘圖示；離線或很久沒同步時，群組上方顯示一行字；往下拉可以手動同步；被移出或授權失效時，用橫幅說明。
- 不輪詢：有變動時，用推播叫醒其他手機去同步；打開 App 時也同步一次。推播透過 Expo 的推播服務。
- 叫醒同步用靜默推播。有人申請加入的通知預設開啟；新支出的通知預設關閉，可以每個群組分開設定。因為加密，推播的文字只能籠統。
- 第一次建立或加入共同帳本時，才請使用者允許通知。

保存和補資料：

- 事件等群組裡每支手機都拿到之後就刪除，最多留 30 天。
- 新成員，以及離線超過 30 天才回來的手機，用另一位成員的手機產生、加密後上傳的快照補資料。快照帶著每個欄位的修改時間，下載後就刪除。
- 沒有其他成員在線時，回來的手機先等，等的時候照樣可以記帳。
- 不自動移除很久沒同步的手機；成員清單上顯示每支手機上次同步的時間。
- 上限：一個事件最大 64 KB，一個群組最多 20 位成員，每支手機每分鐘最多 60 個請求；只同步文字資料，不同步照片。

## 不做

- 帳號和登入：屬於下一個階段。
- 一位成員同時用好幾支手機：要等帳號。
- 永久的換機碼：手機遺失時找回自己的資料，交給帳號和雲端服務。
- 即時連線（WebSocket）：等真的有人覺得同步太慢再考慮。
- 同步照片和附件。
- 管理員和權限分級：等真的有需要，例如之後由建立者付費。
- 第三方的延遲深層連結服務：要多接一家服務，也會蒐集追蹤資料。
